# 超謝罪会見 Ver.1.3.1 — PLAYER RECORDS

ASOBEAT の無料スマートフォンブラウザゲーム。**3回のタイミング謝罪 → 必殺のお辞儀 → 右に進む超巨大衝撃波が惑星を次々に破壊**する2Dゲームです。

Ver.1.3で採用した「衝撃波の常時追尾・接触即爆発」の爽快感は維持し、Ver.1.3.1では**プレイヤー名の初回登録・自動引き継ぎ・名前付き記録の保存・履歴表示**を追加しました。

Ver.1.3の焦点は、従来の「1惑星を見せ終わってから次へ」ではなく、**カメラが衝撃波を追い続け、惑星への接触時に直ちに破壊判定と爆発が始まる**方式です。衝撃波と破壊アニメは独立して進み、前の爆発が終わるまでカメラを止めません（衝突の瞬間の短いヒットストップを除く）。

## ファイル

- `index.html`：ゲーム本体。CSS、JavaScript、画像風アート、Web Audio合成SEを1ファイルに内蔵。**外部CDN・画像素材・API不要**。
- `README.md`：本書と操作説明・GitHub Pages公開手順。
- `TEST_REPORT.md`：検証環境、チェック項目、未検証事項。
- `BALANCE_REVIEW.md`：ゲームバランスの辛口評価、改善優先順位、変更点の技術説明。
- `tests/qa_extended.py`：従来ゲーム機能のPlaywright回帰テスト。
- `tests/qa_checks.json`：従来ゲーム機能62項目の実行結果。
- `tests/qa_player_names.py`：プレイヤー名・保存・変更・旧データ互換・履歴の追加テスト。
- `tests/qa_player_names_results.json`：追加84項目の実行結果。
- `screenshots/`：縦長スマホの参考キャプチャ。実際のプレイ時はアニメーションします。

## 遊び方

1. `index.html`をPCのブラウザで開くか、GitHub Pagesに公開してスマホでアクセス。
2. **「謝罪会見を始める」**を押す。**初回だけ名前入力画面**が表示されます。12文字以内で登録するか、初期値の「匿名」のまま「この名前で謝罪する」を押してください。
3. 2回目以降は登録した名前を自動使用し、再入力なしでゲームが始まります。
4. 1〜3声目のそれぞれで左右に移動する針を見て、中央の明るい目標へ**タップ／クリック**。PCなら**Spaceキー**でも入力できます。
5. 3回の入力後、棒人間が最終謝罪。水星の会見場から右方向へ衝撃波が発射されます。
6. カメラが波を追尾。金星→地球→火星→木星→土星→天王星→海王星の順に衝突します。
7. 結果画面でプレイヤー名、J（ジュール）、惑星別破壊状況、最大コンボ、称号、次に改善するポイント、端末内ランキングを確認。
8. **「もう一度謝罪する」**で同じ名前のまま再挑戦、**「Xで共有する」**で投稿画面、**「結果画像を保存」**で名前付き1200×630pxのPNGを保存できます。

音は最初のタップ後に有効になります。右上の `♪ ON/OFF` で切り替え、`演出 ON/軽` で負荷や点滅を下げられます。飛行中の「演出をスキップ」で結果へ進めます。

### プレイヤー名・記録の新仕様（Ver.1.3.1）

| 項目 | 動作 |
| --- | --- |
| 初回登録 | 最初に「謝罪会見を始める」を押したときだけ名前入力を求めます。初期値は **「匿名」**。 |
| 名前の長さ | 最大12文字。空欄・空白のみは「匿名」に統一します。 |
| 次回のプレイ | 一度登録すると同じブラウザからの次回アクセス時も名前を読み込み、登録画面を省略します。「匿名」で登録した場合も省略します。 |
| 名前変更 | タイトル画面「名前変更」または結果画面「次回の名前を変更」で任意に変更できます。**以前のスコアの名前は変更されません**。 |
| 保存する記録 | 1プレイごとに**名前、J値、日付、称号、到達惑星**等を記録。ランキング表示と「プレイ履歴」から確認できます。 |
| ランキング | 「歴代TOP」「本日のTOP」に名前とJ値を表示。「プレイ履歴」は最新12件から、さらに10件ずつ表示できます。 |
| 記録容量 | このブラウザに**最新500件まで**保持します（501件目以降は古い順に削除）。 |
| 自己ベスト | 今回プレイした名前と一致するスコアから算出します。 |
| 以前の記録 | Ver.1.2／1.3と同じ保存キーを使用して読み込みます。以前の**名前なしスコアは「匿名」**として表示。既存のJ値は維持します。 |
| 結果の公開 | X共有文とPNG画像に登録名が入ります。本名を公開したくない場合は「匿名」やニックネームを使ってください。 |

**重要：記録はオンライン送信されません。** ブラウザの`localStorage`へ保存する方式で、GitHub Pagesだけで動作します。別のスマホ・別のブラウザ・別のドメインとの共通ランキングはありません。シークレットモード、サイトデータ消去、ストレージ制限などでは保持できない場合があります。複数端末の全ユーザー記録を共有したい場合は別途データベース等のバックエンドが必要です。

### 判定の目安

| 判定 | 目標中心からの距離（ゲージ全体に対する％） |
| --- | ---: |
| 神謝罪（パーフェクト内の特別判定） | ±0.25％以内 |
| パーフェクト謝罪 | ±0.8％以内 |
| 超Good謝罪 | ±4.5％以内 |
| Good謝罪 | ±9.0％以内 |
| なかなか謝罪 | ±15.0％以内 |
| まあまあ謝罪 | ±23.0％以内 |
| ちょっと謝罪 | ±34.0％以内 |
| NO謝罪 | 上記以外、または時間切れ |

Ver.1.2のパーフェクト±0.9％から、Ver.1.3では**±0.8％**へ狭めています。ユーザー案の±1.5〜2％は旧版より広がるため、その案より「実際に狭くする」要件を優先しました。3回とも±0.25％以内なら特殊な「神謝罪×3」補正が入ります。

**端末フレーム数でタイミング判定を進めず、`performance.now()` の経過時間で針位置・入力判定を計算します。** 目標位置は固定、針速度は声ごとに異なりますが規則的です。得点計算に隠し乱数は使いません。

### J値・破壊判定について

- 精度3回の情報を重み付けしたスコアを100万分の1の固定単位に変換し、13乗カーブとボーナスで計算します。
- **100万分の1へ量子化した後の巨大数計算、惑星閾値比較、表示、順位比較はすべて `BigInt`** です。桁落ちする `Number` へ戻しません。
- 惑星ごとの破壊閾値は**ゲーム上の架空値**であり、天体の実際の重力結合エネルギーを表すものではありません。破壊順を水星→海王星に保つためのゲームデザインです。
- 完全崩壊した惑星はコンボ数が増えます。半壊・亀裂なら破片や焦げが残り、次の惑星へ進める場合があります。衝撃が無傷で阻止された場合は波が消えます。

## GitHub Pages公開方法（無料）

1. GitHubで新しい**公開リポジトリ**を作成。
2. ZIPを解凍し、その中の **`index.html`をリポジトリの最上位**にアップロード。`README.md`等はアップロードしてもしなくてもゲーム動作に影響しません。
3. リポジトリの `Settings` → `Pages` を開く。
4. `Build and deployment` → `Deploy from a branch` を選び、Branchを `main` / `/(root)` にして保存。
5. Pages画面に発行されたURLを開いて動作を確認。**HTTPS公開**ならX共有文へゲームURLが入ります。

サーバー不要・APIキー不要・課金不要で動きます。ただしGitHubの提供条件や操作画面は変更される場合があります。

## iPhone Safariでの注意

- ブラウザの音声再生制限に従うため、必ずゲーム開始をタップして音声を有効にしてください。
- 画像保存ボタンはPNGのダウンロードを開始します。iOSのバージョン・設定によってはダウンロード先がファイルアプリ等になります。
- X共有はポップアップで投稿画面を開きます。ポップアップ制限中は投稿文コピーの案内へフォールバックします。**登録名を共有文に含めます**。
- 名前と端末内ランキングはブラウザの`localStorage`へ別々のキーで保存します。シークレットモードやサイトデータ削除で失われることがあります。**世界共通ランキングではありません。**
- Safari実機での音量バランス・連続プレイの発熱・フレームレートは未検証です。公開前に実機確認してください。

## 技術構成

- Canvas 2D、CSS、純粋なJavaScript。`requestAnimationFrame`駆動。
- 衝撃波の仮想座標 `waveX` にカメラを追従させ、相対座標で8惑星を描画。**惑星ごとの待機シーンを廃止**。
- `impactEvents`に衝突時刻・破壊状態を記録し、**波の運動と独立して赤熱・亀裂・巨大破片・爆炎・リングを進行**。
- 1惑星ごと約75ms、最初の水星約85msのヒットストップ。衝突演出は同時に開始。
- コンボに応じて波の速度、星の流線、漫画テロップ、合成BGM、コンボSEを強化。
- Web Audio APIによる衝突音／爆発音／崩壊音の多層構成。音素材ファイルは不要。
- 描画用粒子を上限管理、惑星テクスチャをキャッシュ、DOMイベントの二重反応は`pressLock`で防止。
- 初回登録をゲーム開始前にガードし、名前は`asobeat_choushazai_player_v1`、スコアは従来の`asobeat_choushazai_v12_records`に保存。旧レコードは名前を補完表示するだけで改変せず互換性を維持。

## 改修前からの主な変更

| 項目 | 従来 | 本バージョン |
| --- | --- | --- |
| カメラ | 惑星到達時に一度止まって判定 | 衝撃波に常時固定（短いヒットストップのみ） |
| 1惑星の演出 | 約3秒の固定区間 | 接触時に即時発火、飛行中に並行再生 |
| 破壊エフェクト | 破片・赤熱・爆炎 | 維持しつつ移動中に重ねて表示、リング・圧縮演出を追加 |
| コンボ | テキスト中心 | 2・3・5・8連続で見せ場、速度と音も段階強化 |
| 入力の最高判定 | ±0.9％ | ±0.8％、神謝罪±0.25％ |
| 威力 | 巨大数にBigInt使用 | 量子化後の13乗スコア曲線までBigInt整数演算 |
| フィードバック | 精度差と到達結果 | 次の惑星に必要なJ差、改善対象の声も表示 |
| リザルト | J、惑星、称号、ローカル順位 | 最大コンボ、次回目標、特別称号も追加 |
| プレイヤー登録 | 名前なし | 初回のみ登録、「匿名」選択可、次回自動利用 |
| ランキング表示 | 名前なしのJ値のみ | 名前・日付・J値、過去履歴、名前別自己ベスト |

## テスト

`TEST_REPORT.md`参照。Chromiumでの自動テストは**既存62項目／追加84項目、計146項目すべて通過**（画面サイズ390×844、375×667、320×568、1000×720を含む）。名前の保存・復元に関する自動チェックは、テスト環境でローカルURLへのナビゲーションが制限されるため**localStorageの模擬実装に保存データを渡して画面を作り直す方式**で実施しています。実際のGitHub Pages環境でページを再読み込みするE2E試験、および**iPhone Safari実機では未検証**です。

自動チェックの再実行にはPythonとPlaywright、Chromiumが必要です。環境変数`CHROMIUM_PATH=/usr/bin/chromium`などを指定し、`python tests/qa_extended.py`と`python tests/qa_player_names.py`を実行してください。ゲーム本体はこれらのテスト用パッケージを必要としません。
