# 超謝罪会見 Ver.1.2 — CINEMATIC WAVE

制作：ASOBEAT／アソビート  |  2Dタイミングアクション・惑星破壊バカゲー

## 起動・公開

- `index.html` をChrome、Edge、Safariなどで開く（保存機能の安定動作にはGitHub Pages等のHTTP(S)公開を推奨）。
- GitHubのPublicリポジトリのルートに `index.html` をアップロードし、Settings → Pages → Deploy from a branch → main / (root) を選ぶと公開できます。
- 追加のAPIキー、外部CDN、画像素材、ライブラリは不要です。音楽・効果音はWeb Audio APIで生成します。
- ゲームはCanvas 2D製で、3D/WebGL不要です。

## 操作

1. 「謝罪会見を始める」をタップ。
2. 「この度は、」「誠に、」「申し訳ございませんでした！！！」で、それぞれ動くゲージの白い針と、移動する金色の中心を合わせて、タップまたはPCのSpaceキーを押します。
3. 全3回のタイミング精度からJ（ジュール）が決定。水星で謝罪した後、衝撃波とカメラが右へ進みます。
4. 各惑星は「衝撃波の接近 → 赤熱 → 亀裂 → 破壊／生存」の順番で描画されます。演出スキップしてもスコアは変化しません。
5. リザルトでは8惑星の破壊段階、巨大なJ値、称号、3回の中心ズレ、端末内ランキングを確認できます。
6. 「Xで共有する」で投稿文、対応端末では結果画像を共有可能です。画像は「結果画像を保存」からPNGとして保存できます。

## Ver.1.2でのグラフィック改修

- 衝撃波を粒状の光球から、ゆがみを持つ複数の層状波面に変更。後方に減衰する気流・細い筋が残ります。
- 衝撃波は左から右へ進み、カメラが追尾。惑星付近でカメラを保持し、判定の一連の流れを見せます。
- 惑星の赤熱が衝突側から時間とともに広がり、徐々に亀裂が増え、完全破壊なら爆発します。
- 爆発は高温のガス雲、暗い煙、複数の圧力リング、星ごとの岩片を重ねた2D表現です。
- 完全破壊でない星は無条件に爆発しません。全て、計算済みのJによる判定に連動します。

## 新しい難易度設計

| 謝罪評価 | 中心からの相対距離 |
|---|---:|
| パーフェクト謝罪 | ±0.9% |
| 超Good謝罪 | ±2.7% |
| Good謝罪 | ±7.2% |
| なかなか謝罪 | ±13.5% |
| まあまあ謝罪 | ±22.5% |
| ちょっと謝罪 | ±34% |
| NO謝罪 | その他・時間切れ |

- ゲージのカーソルは周期内で**非等速**に動きます。金色の判定帯も**画面上で確認できる速度**で移動します。
- 第1声→第3声と針の移動が速くなり、判定帯の揺れも大きくなります。
- リトライごとにターゲットの軌道位相を変化させるので、固定時刻の連打だけでは攻略できません。
- 入力はイベントが発生した瞬間の時間を補間して判定。表示フレームからの遅れを抑えます。
- セリフ別の中心ズレ（%）を確認し、毎回修正しながら上達できます。
- 入力ごとの結果→スコアは決定論的です。J値と惑星の破壊結果に**隠れた乱数補正はありません**。

## ランキング／X共有

- この版のランキングは**同じ端末・同じブラウザ**に保存された実スコアです。世界ランキングはオンラインDBが未接続なので表示しません。
- 今日／歴代の順位、自己ベスト、今回の順位が表示されます。ブラウザストレージが利用できないモードでは永続保存できません。
- Xに添付画像を強制するAPIは実装していません。対応ブラウザでの共有シート、それ以外では画像保存＋Xへの投稿文を利用してください。
- 共有画像は1200×630px PNGで、J値と破壊到達状況を含みます。

## 注意事項

- このゲームで使用するJの値・惑星の破壊耐性は、**ゲーム用の架空設定**です。
- グラフィックは2D Canvasによる視覚表現で、リアルな流体力学・物理シミュレーションを計算しているわけではありません。
- iPhone Safari実機、Android実機、Xアプリ投稿画面については、この制作環境では実機テストできていません。
- 画面の揺れや光が強い場合は上部の「演出」を軽減してください。
