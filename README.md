# 超謝罪会見 Ver.1.1.1 — 再構築版

ASOBEATのスマートフォン・PC向け2Dタイミングバカゲー。**index.html だけで動作**します。外部API・CDN・画像読み込みは不要です。

## 公開
GitHubの新しいPublicリポジトリ直下に `index.html` を置き、Settings → Pages → Deploy from a branch → main / (root) を選択します。

## 遊び方
1. 「謝罪会見を始める」を押す。
2. 「この度は、」「誠に、」「申し訳ございませんでした！！！」の3回、それぞれのゲージでタイミングよくタップ。PCはSpaceキーも対応。
3. 水星から右に向かって衝撃波が進み、各惑星に到達→判定→破壊演出を繰り返します。
4. リザルトではJ値・惑星別状態・称号・この端末のランキングを確認できます。結果PNG保存・X共有もあります。

## 判定幅（ゲージ全長に対して）
パーフェクト謝罪 ±2%、超Good謝罪 ±5%、Good謝罪 ±10%、なかなか謝罪 ±16%、まあまあ謝罪 ±24%、ちょっと謝罪 ±35%、その他 NO謝罪。
タイムアウトもNO謝罪。ゲージの中心への距離は判定名と別にスコアへ連続的に反映され、同じ称号でもJが変わります。

## ランキングについて
このビルドで稼働するのは **ブラウザ内の実記録ランキング** です。歴代TOP・本日分・今回順位・自己ベストをlocalStorageに最大200件保存します。異なる人や端末を横断する世界ランキングではありません。世界ランキングには別途バックエンド・不正スコア対策が必要です。架空のオンライン順位やAIプレイヤーは表示しません。

## 結果の共有
Xの投稿画面を開き、本文をコピーします。対応ブラウザではWeb Share APIによるPNG付き共有を試みます。Xの仕様や端末によって自動画像添付ができないため、画像保存して手動添付してください。iPhone Safariでは画像の保存先や共有ダイアログが異なる場合があります。

## 計算の扱い
惑星耐久値はゲーム専用の架空値で、現実の天体物理ではありません。J値はBigIntで保持し、最終スコアの丸め精度を高めています。カメラと破壊の見た目は計算済み結果に追従し、スキップしても結果は変わりません。

## 操作環境
スマートフォン縦画面を最優先、横画面・PCにも対応。音量切替と演出軽減ボタンあり。端末性能に応じて重いアニメーションに差が出ます。iPhone Safari実機検証は別途必要です。
