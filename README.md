# 超謝罪会見 Ver.1.4 / 全国オンラインランキング

**1 ファイル HTML + Firebase Authentication + Cloud Firestore**

## 先にFirebaseのセキュリティルールを公開

1. Firebase Console の `asobeat-91aef` プロジェクトを開く。
2. 「構築 → Firestore Database → ルール」を開く。
3. `firestore.rules` ファイルを開いて、全体をコピーし、既存のルールを置き換える。
4. 「公開」を押す。**これをしないとオンライン記録の保存・表示ができません。**
5. 「構築 → Authentication → Sign-in method → 匿名」が有効になっていることを確認する。

ルールは `bestScores/{認証uid}` と `weeks/{YYYY-Www}/scores/{認証uid}` のみを許可します。プレイヤーは自分の記録しか書き換えられず、勝手に他人の記録を削除できません。ただし、ブラウザゲームでプレイ結果はクライアントが計算するため、不正な高スコアの送信を完全には防げません。本番運用での賞品付きイベントは、サーバーでのプレイ検証を導入するまで非推奨です。

## GitHub Pages公開

1. このフォルダーの `index.html` をGitHubリポジトリのルートに上書きアップロード。
2. Commit changes する。
3. GitHub Pagesが反映されると、同じURLでVer.1.4が動作。
4. 1回プレイしてリザルトの「全国オンラインランキング」に `接続中` / `記録を同期しました` が表示され、名前とJ値が載ることを確認。
5. 別ブラウザ・別端末で開いて歴代TOP100に見えることを確認。

Firebaseプロジェクトの認証ドメイン（Authentication → 設定 → 承認済みドメイン）でGitHub Pagesのホストが必要とされる場合は `ユーザー名.github.io` を追加してください。匿名認証のみの実装では通常、Googleログイン等のリダイレクトは使いません。

## 保存仕様

- 初回名前登録はVer.1.3.1から維持。ローカルストレージ内に残る。
- 完了時のJ値は **文字列** で保存。ランキング順位には48桁のゼロ埋め文字列 `scoreKey` を利用。数字の精度はBigIntで保つ。
- `bestScores` はUIDごとの歴代ベスト1件。
- `weeks/{週ID}/scores` はUTC月曜日開始の週ごとのベスト1件。
- リザルトにTOP100とその週の順位を表示。自分のスコアがTOP100外なら圏外と表示。
- 以前のローカル記録のオンライン自動移行はしません（チートを抑制するため）。アップデート後の新規プレイから投稿。
- 別の端末やブラウザの匿名アカウントは同一人物と判定されません。ブラウザデータ消去でもUIDが変わる場合があります。
- ネット切断やFirebase障害時も従来のローカルプレイと履歴は利用できます。

## 既知の制約

- **Firebase実環境接続・Firestoreへの書き込み・iPhone Safari実機**はこの納品時点で未確認です。Firebase Console上の設定を開発環境から確認できないため、実機で上の手順による最終テストが必要です。
- セキュリティルールではUID一致、フィールドの型/長さ、スコア更新の単調増加を制限していますが、クライアントから任意にスコアを作成する問題は完全には対策できません。
- オンライン取得は表示のたびに最大100件読み込みます。無料枠の使用量に注意。
- Firebase SDKは公式Google CDNのモジュールを読み込みます。オフライン時には読み込めないためオンラインランキングのみ停止。

## トラブル対応

- `アクセス拒否` → firestore.rulesの公開を確認。
- `Firebaseで匿名認証を有効に` → Authenticationで匿名をオン。
- `接続できません` → ネット、Firebase設定、Firestore Database作成状況を確認。
- `ランキングがない` → 最初のプレイ後に記録を投稿し、更新ボタンを押す。
