# 超謝罪会見 — ASOBEAT Ver.1.0.0

> 水星で謝罪会見をしたら、お辞儀が強すぎて太陽系が崩壊した。

ASOBEATのオリジナル2Dブラウザ・バカゲーです。**プレイヤーの操作は3回のタイミングタップだけ。** 水星・金星・地球・火星・木星・土星・天王星・海王星に、謝罪の衝撃波を送り込みます。

## 公開方法（GitHub Pages）

**GitHubにアップロードするファイルは `index.html` 1つだけです。** サウンドとグラフィックはWeb Audio APIとCanvas 2Dのコードで生成します。CDN・画像素材・APIキーは不要です。

1. GitHubに公開リポジトリを作る（推奨名：`choushazai`）。
2. `index.html` をリポジトリ直下にアップロードしてコミット。
3. `Settings → Pages` → `Deploy from a branch` → ブランチ `main`、フォルダ `/(root)` に設定。
4. Pagesの「Visit site」から公開ページを開きます。
5. タイトル下部に `Ver.1.0.0` と表示されれば今回の版です。

利用中のGitHubユーザーが `asobeatapps-ops` で、リポジトリ名が `choushazai` **の場合**、公開URLの形式は `https://asobeatapps-ops.github.io/choushazai/` です（アップロード・公開済みであることは未確認）。

## 遊び方

1. タイトル画面で「謝罪を始める」。
2. 主人公が「この度は、」と言うとタイミングゲージが開始。中央の黄色いゾーンに動く白い線を重ねてタップ。
3. 「誠に、」と「申し訳ございませんでした！」でも同じ操作。合計 **3回** の判定です。
4. 3回の精度から確定した**最終謝罪威力 J**で、お辞儀と惑星破壊を自動進行。
5. 演出は「演出をスキップ」で省略可能。**スキップしてもJ値や破壊結果は変化しません。**
6. リザルトで8惑星の被害、最終J、称号を確認し、再挑戦やX共有を行います。

スマホでは画面タップ／黄色いボタン、PCではマウスクリックまたはSpaceキー。タイミングゲージは最初の短いセリフ後に動き始め、押さずに約4.8秒経つと自動MISSとなります。フレームレートに依存しない判定です。

## 判定と宇宙破壊

- PERFECT：中心から±5％以内
- GREAT：中心から±12％以内
- GOOD：中心から±25％以内
- MISS：それ以外
- 同じPERFECTでも中心に近いほど強力です。隠れた乱数で最終威力が変わることはありません。
- 3連続PERFECTで威力ボーナス、特別演出「土下座・最終形態」。さらに高精度なら「謝罪、臨界突破。」になります。
- 3回の精度を、非線形関数で約10^12～10^29 Jの威力に変換。**BigIntで大きな整数を保持**し、結果画像・X投稿文にも同じ正確な数値を使用。
- 惑星には水星10^13、金星10^15、地球10^17、火星10^19、木星10^21、土星10^23、天王星10^25、海王星10^27 J級の難易度を設定。
- 各惑星に「無傷／亀裂／一部破壊／半壊／完全崩壊」の5段階判定。破壊は水星→海王星の順。衝撃波は先に進むほど少し減衰します。

**注意：これらのJ値は架空のゲームバランス値であり、実際に惑星を破壊する物理学上の必要エネルギーを表したものではありません。**

## 2D演出・サウンド

- 水星の記者会見場・スーツ姿の主人公・カメラマンをCanvas 2Dで描画。
- 8惑星のテクスチャ、木星の縞模様、地球の海・陸・雲、土星のリング、亀裂と崩壊破片を生成。
- ヒットストップ風演出・衝撃波・光源・集中線・ズーム・カメラ揺れ。
- BGMと効果音はWeb Audio APIによるオリジナルの簡易シンセサウンド。
- 実況は巨大な日本語テロップを常に表示。右上「実況 ON」にすると、利用可能な端末ではブラウザの日本語音声読み上げを試みます。端末・日本語音声の有無で発声品質は変わり、読み上げは保証できません。
- `prefers-reduced-motion` が有効な端末では一部の点滅・画面揺れを抑えます。

## X共有と保存

結果画像は**1200×630ピクセルのPNG**で生成され、最終J・8惑星・称号が入ります。

1. 「Xで結果を共有」：iPhone等でファイル共有が可能な場合は共有シートを呼び出します。
2. 対応しない場合は投稿文章のコピーとX投稿ページへのリンクを使えます。
3. 「結果画像を保存」でPNGを保存し、Xに添付してください。

**ブラウザの制約によりXへの画像添付・投稿完了を自動保証することはできません。** 初回の紹介投稿用ハッシュタグは指定どおり `#ゲーム開発 #gamedev` のみです。

## ソース構成

```text
index.html             GitHub Pages公開用（単独で動作）
build.py               ソースをHTMLへ結合
src/template.html      HTML UI構造
src/style.css          UIスタイル
src/game.js            Canvas描画／ゲーム進行／音／共有
tests/qa_suite.py      ブラウザの操作・計算・レスポンシブ回帰テスト
tests/flow_verify.py   時間切れMISSと破壊演出の自動完走
TEST_REPORT.md         実施したテストと未検証点
BALANCE_NOTES.md       辛口の企画評価・今後の改善候補
```

ソースを修正したら `python3 build.py` で `index.html` を再生成できます。ビルドにはPython標準ライブラリのみで十分です。ブラウザ自動テストにはPlaywrightとChromium、画像確認にはPillowが必要です。

## 公開前に必要な実機確認

Linux Chromiumのブラウザと計算テストは実施済みですが、**iPhone Safari実機の音・タッチ・処理速度・長時間発熱、実際のXアプリでの共有挙動は未検証**です。特に、3回のジャスト判定が実機の指遅延でも気持ちよいかを確認してください。
