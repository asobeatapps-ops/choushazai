# 超謝罪会見 Ver.1.3 — 惑星粉砕アップデート

ASOBEATのスマートフォン向け2Dタイミングゲームです。

## 公開方法

GitHubの公開リポジトリのルートへ `index.html` を配置し、Settings → Pages で `main / (root)` を選択してください。外部APIキー・ビルド操作・サーバーは必要ありません。

## 操作

「謝罪を始める」を押して、セリフが表示されるたびにゲージの目標へ針が重なるタイミングでタップしてください。合計3回です。PCはSpaceキーでも操作できます。破壊演出は「スキップ」可能です。右上で音量・演出の軽量化を切り替えられます。

## Ver.1.3で改善した点

- 衝突から熱伝播・亀裂・崩壊にかけての段階的演出
- 大きな地殻片13個と、小さな岩片96個で惑星の粉砕を描画
- 熱い中心から広がる不規則な爆炎、外縁の煙、三重のリング状圧力波
- 衝突時の圧縮波面と短い“間”
- 衝突音・低域衝撃音・崩落音の3層化
- 連鎖粉砕COMBOの実況
- 各入力の中心からの誤差率と改善メッセージ
- 7段階謝罪、巨大J値（BigInt）、8惑星破壊判定、端末内ランキング、結果PNG/X共有

## 仕様上の限界

実写・数値流体解析ではなくCanvas 2Dによる演出的な破壊表現です。惑星の耐久値とジュール値はゲーム用の架空設定です。端末内ランキングはブラウザのlocalStorageに保存され、実際のオンライン世界順位ではありません。Xアプリへの画像の自動添付はブラウザによって異なるため、結果画像を保存して手動添付する経路も用意しています。音声はブラウザのWeb Audio合成で、端末により音色が異なります。
